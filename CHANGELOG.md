## [1.0.0] - 2025-01-15

### Added

- Full-stack SaaS starter with authentication
- Plan-based subscriptions (Free / Pro / Enterprise)
- Usage quotas and rate limiting
- API key management
- Dashboard with API playground
- Dark/light theme support
- Docker and Docker Compose support
- Comprehensive DevSecOps CI/CD pipeline
- Terraform infrastructure for EKS
- Helm charts and ArgoCD GitOps manifests
- End-to-end API test suite (17 tests)

### Security

- bcrypt password hashing
- JWT with httpOnly cookies
- Input validation and security headers
- Secrets scanning, SAST, and dependency scanning in CI
